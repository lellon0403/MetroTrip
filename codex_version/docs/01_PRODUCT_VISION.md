# 제품 비전

## 한 문장

MetroTrip은 지하철 이동을 여행의 제약이 아니라 일정의 뼈대로 바꾸어, 역 주변을 발견하고 동선을 만들고 경험과 동행을 나누게 하는 도시 여행 서비스다.

## 해결하려는 문제

`CONFIRMED` 기존 계획서는 자차가 없는 20대·사회초년생이 저비용으로 여행하기 어렵고, 역 주변 장소와 이동 정보를 여러 앱에서 따로 찾아야 한다는 문제를 제시한다.

`INFERRED` 실제 사용자 문제는 “장소를 모른다” 하나가 아니다.

1. 어디서 내릴지 결정하기 어렵다.
2. 역 주변에서 무엇을 할지 지도·검색·후기를 오간다.
3. 장소를 골라도 지하철 이동과 방문 순서를 함께 계산하기 어렵다.
4. 실제 경험과 동행 모집이 이동 계획과 분리되어 맥락이 사라진다.

## 제품 포지셔닝

MetroTrip은 네 가지 층을 하나의 여행 문맥으로 연결한다.

| 층 | 사용자 질문 | 제품의 답 |
|---|---|---|
| Transit | 어떻게 가고 언제 탈까 | 노선·역·시간표·경로 |
| Local discovery | 어디서 내리고 무엇을 할까 | 지도 중심 역 주변 장소 탐색 |
| Travel planning | 어떤 순서로 움직일까 | 경로 기반 일정 작성·공유 |
| Community | 먼저 다녀온 사람과 같이 갈 사람은 | 후기·토론·동행 모집 |

경쟁 제품을 모두 대체하지 않는다. 범용 내비게이션의 실시간 운행 정확도, 범용 지도 검색의 장소량, 대형 커뮤니티의 규모보다 “지하철 여정”이라는 공통 객체로 기능을 잇는 데 집중한다.

## 핵심 사용자

| 사용자 | 상황 | 최우선 가치 |
|---|---|---|
| 탐색형 여행자 | 주말에 가까운 곳을 즉흥적으로 찾음 | 역 단위 발견, 짧은 의사결정 |
| 계획형 여행자 | 여러 장소와 시간을 미리 조합함 | 이동과 방문 순서의 일관성 |
| 현장 사용자 | 이동 중 다음 열차·장소를 확인함 | 빠른 모바일 접근, 위치 문맥 |
| 경험 공유자 | 사진·동선·비용을 후기화함 | 계획 재사용이 가능한 구조화된 후기 |
| 동행 모집자 | 같은 일정의 사람을 모음 | 계획 연결, 정원·마감·신청 관리 |
| 운영자 | 데이터 품질·신고·공지 관리 | 감사 가능한 변경과 최소 권한 |

## 핵심 제품 루프

`역/경로 탐색 → 주변 장소 저장 → 여행 계획 구성 → 현장에서 사용 → 후기 작성 → 다른 사용자가 계획 복제 또는 동행 신청`

루프가 끊기지 않도록 역, 장소, 계획, 후기, 모집글을 링크 가능한 1급 리소스로 설계한다.

## 제품 원칙

1. 지도 먼저, 목록은 판단을 돕는다. 지도와 목록 어느 쪽도 다른 쪽의 장식이 아니다.
2. 이동 근거를 숨기지 않는다. 실측 시간표와 추정값을 명확히 구분한다.
3. 커뮤니티는 콘텐츠가 주인공이다. 작성자·맥락·정렬·댓글 구조는 Reddit의 정보 밀도를 참고하되 시각 디자인은 복제하지 않는다.
4. 계획은 문서가 아니라 실행 가능한 순서다. 역·장소·시간·이동 구간을 구조화한다.
5. 웹과 모바일은 같은 계정·데이터를 공유하지만 동일 화면을 축소하지 않는다.
6. 기능 수보다 신뢰할 수 있는 데이터 범위를 우선한다.
7. 공개 읽기와 인증 쓰기를 구분해 첫 사용 장벽을 낮춘다.

## 성공 지표

### 북극성 지표

주간 `완성된 여행 세션` 수. 다음 중 하나를 충족하면 완성으로 본다.

- 계획에 장소 2개 이상을 저장하고 공유함
- 저장한 계획을 여행 당일 모바일에서 열어봄
- 후기에서 계획을 공개해 다른 사용자가 저장·복제함

### 선행 지표

| 단계 | 지표 |
|---|---|
| 탐색 | 역 선택 후 장소 상세 진입률, 무결과율 |
| 저장 | 장소·역 즐겨찾기 전환율 |
| 계획 | 계획 시작 대비 장소 2개 이상 완성률 |
| 현장 | 여행일 계획 재방문율, 시간표 조회 성공률 |
| 공유 | 후기 작성 완료율, 계획 복제율, 모집 신청률 |
| 신뢰 | 데이터 오류 신고율, 추정 시간 표시 비율, 신고 처리 시간 |

페이지뷰·체류시간은 보조 지표이며 목적 지표로 최적화하지 않는다.

## 비전에서 제외하는 것

- 항공·숙박·렌터카 예약 플랫폼
- 자동차 내비게이션
- 모든 도시를 즉시 지원하는 범용 지도 데이터베이스
- AI가 근거 없이 일정을 자동 생성하는 기능
- 결제·정산·에스크로
- 소셜 피드 자체가 목적이 되는 팔로워 경제

`OPEN` 첫 출시 지역은 천안·아산 검증 후 수도권 1호선으로 확장할지, 처음부터 수도권 주요 노선으로 갈지 결정이 필요하다.
