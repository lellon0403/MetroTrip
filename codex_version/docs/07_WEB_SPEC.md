# 웹 제품 명세

## 웹의 역할

웹은 넓은 화면에서의 지도 탐색, 복잡한 여행 계획 편집, 긴 후기·커뮤니티 읽기, 검색 유입, 관리자 작업을 담당한다. 공개 리소스는 서버 렌더링으로 공유·검색 가능하게 한다.

## 공통 셸

- 데스크톱: 상단 글로벌 내비게이션 + 콘텐츠 영역. 지도 화면만 뷰포트 전체를 사용한다.
- 태블릿: 상단 내비게이션 유지, 지도/목록 비율 축소.
- 모바일 웹: 하단 주요 내비게이션을 선택적으로 사용하되 네이티브 전용 기능을 가장하지 않는다.
- 콘텐츠 폭은 [06_UI_UX_DIRECTION.md](06_UI_UX_DIRECTION.md)의 토큰을 사용한다.

## 후기 목록 레이아웃

- 기본은 2열 또는 3열 masonry가 아니라 높이가 예측 가능한 반응형 그리드/리스트다. 긴 제목·태그로 읽기 순서가 흔들리지 않게 한다.
- 이미지 중심 탐색이 검증되면 선택형 `갤러리 보기`를 제공할 수 있다.
- 카드 하단 메타데이터 순서: 경로·평점 → 작성자·날짜 → 조회·도움됨·댓글.
- 태그 영역은 한 줄 `overflow: hidden; white-space: nowrap` 컨테이너와 측정된 `+N` 배지를 사용한다.

## 계획 편집 데스크톱 레이아웃

- 왼쪽 56~64%: 지도와 이동 경로.
- 오른쪽 36~44%: 날짜별 일정 타임라인.
- 장소 검색은 우측 패널 안의 임시 모드로 열어 현재 계획 문맥을 잃지 않는다.
- 저장 상태는 `저장 중/저장됨/충돌/오프라인`으로 헤더에 지속 표시한다.

## SEO·공유

- 공개 역·장소·후기·모집·공유 계획만 인덱싱한다.
- 사용자 마이페이지, 초안, 필터 조합 URL은 `noindex`다.
- Open Graph에는 제목·대표 이미지·역/경로·작성자 표시명을 포함하되 개인정보는 제외한다.
- 삭제·회수된 공개 리소스는 의미 있는 404/410을 반환한다.

## 웹 전용 수용 기준

- 새로고침·직접 URL 접근으로 모든 공개 화면이 열린다.
- 뒤로가기가 지도 위치·필터·스크롤 문맥을 복원한다.
- 자바스크립트 로딩 전에도 공개 상세의 핵심 텍스트가 보인다.
- 키보드만으로 검색→역→장소→계획 추가 흐름이 가능하다.
