## 확인해야 할 현행 근거

- 원격 저장소 최신 상태: 현재 sandbox의 `.git/FETCH_HEAD` 권한 문제 해소 후 fetch 재확인
- Drive 요구사항 V1.4 또는 모집 게시판 정식 요구사항 ID 존재 여부
- 최신 ERD가 V1.10 DB 명세와 동기화됐는지
- 장소 원본 content ID와 급행 열차 필드를 DB 담당이 후속 추가했는지
- 개인정보·탈퇴 정책을 팀이 별도로 합의한 문서가 있는지
