# UI/UX 방향

## 디자인 문장

“여행 계획 도구의 명료함, 지도 탐색의 공간 감각, 커뮤니티의 정보 밀도를 하나의 차분한 인터페이스로 묶는다.”

## 시각 원칙

- 기본 배경은 밝은 중성색, 콘텐츠 표면은 흰색 또는 한 단계 높은 표면색을 사용한다.
- 주색은 선명한 지하철 블루 하나로 제한하고 노선색은 데이터 표시에만 사용한다.
- 그림자보다 1px 경계와 간격으로 구조를 만든다.
- 모서리 반경은 6/10/14px 세 단계로 제한한다.
- 제목·본문·메타데이터의 크기 차이를 충분히 두고, 모든 정보를 카드로 감싸지 않는다.
- 사진·지도·노선도가 시각 중심이며 장식용 그라디언트와 빈 히어로는 쓰지 않는다.
- 글 목록은 Reddit처럼 작성자·시간·반응·댓글·연결 맥락을 빠르게 읽을 수 있게 하되 투표 UI를 무조건 도입하지 않는다.

피할 것:

- AI 대시보드처럼 보이는 지표 카드 군집
- 글래스모피즘, 과도한 블러·그라디언트
- 모든 영역의 큰 둥근 카드화
- 정보가 없는 대형 환영 문구
- 데스크톱 3열을 모바일에 단순 축소

## 디자인 토큰

| 범주 | 토큰 예시 | 원칙 |
|---|---|---|
| 폭 | `content-sm 720`, `content-md 960`, `content-lg 1200`, `map-full` | 페이지별 임의 max-width 금지 |
| 간격 | 4, 8, 12, 16, 24, 32, 48, 64 | 4px 기반 |
| 글꼴 | display 40/48, h1 32/40, h2 24/32, body 16/24, meta 14/20 | 한국어 시스템/가변 산세리프 |
| 색 | primary blue, semantic success/warning/error, neutral scale | 대비 AA |
| 깊이 | border, sticky elevation, modal elevation | 일반 카드 그림자 최소화 |
| 모션 | 120~240ms, 거리 4~12px | 상태 설명 목적, reduced motion 지원 |

후기 목록·상세·작성과 모집 목록·상세·작성은 모두 `content-lg` 토큰을 공유한다. 본문 읽기 열은 내부에서 `content-sm`로 제한할 수 있지만 헤더와 구분선의 외곽 폭은 일치한다.

## 지도와 목록

### 데스크톱

- 지도 60~68%, 목록 32~40% 분할을 기본으로 한다.
- 목록 선택은 지도 마커 강조와 동기화한다.
- 필터는 상단 한 줄, 고급 필터는 팝오버/패널로 연다.
- 지도 이동 후 `이 영역 검색`을 명시적으로 눌러 요청 폭주를 막는다.

### 모바일

- 지도 전체 화면 + 하단 시트 구조를 사용한다.
- 시트는 최소/중간/전체 세 높이로 스냅한다.
- 마커 선택 시 시트가 장소 미리보기로 전환된다.
- 필터는 가로 칩과 전체 화면 필터 시트를 병행한다.

## 커뮤니티 화면

- 목록은 이미지가 있으면 96~160px 썸네일, 없으면 텍스트 행으로 표시한다.
- 제목 2줄, 본문 미리보기 2~3줄, 태그는 한 줄에서 보이는 만큼만 표시하고 `+N`도 같은 줄 안에 보장한다.
- 조회·도움됨·댓글은 동일한 메타데이터 행에 둔다.
- 상세는 제목과 작성자, 연결된 역/계획, 본문, 반응, 댓글 순이다.
- 작성 화면은 입력 폼보다 콘텐츠 편집기가 주인공이며 자동 저장 상태를 표시한다.

## 상태 설계

모든 주요 화면은 다음을 갖는다.

| 상태 | 원칙 |
|---|---|
| 초기 로딩 | 실제 레이아웃과 유사한 skeleton; 전체 스피너 금지 |
| 부분 로딩 | 기존 콘텐츠 유지, 갱신 위치만 표시 |
| 빈 상태 | 이유, 현재 필터, 다음 행동 하나를 제시 |
| 오류 | 사용자 언어, 재시도, 데이터 출처/연결 상태를 구분 |
| 권한 필요 | 현재 작업을 보존하고 로그인 뒤 복귀 |
| 오프라인 | 마지막 동기화 시각과 수정 가능 범위 표시 |
| 성공 | 토스트만 의존하지 않고 화면 상태를 즉시 갱신 |

## 접근성

- 지도 외에 동등한 장소 목록과 역 검색을 제공한다.
- 노선색만으로 노선을 구분하지 않고 이름·패턴·텍스트를 병기한다.
- 드래그 정렬에는 위/아래 이동 버튼과 키보드 조작을 제공한다.
- 별점은 각 값의 접근 가능한 이름과 키보드 조작을 제공한다.
- 모달은 초점 가두기, 복귀, Escape 닫기를 지킨다.
- 최소 터치 목표 44px, 텍스트 대비 4.5:1을 적용한다.

## 다크 모드

- 사진·지도 타일을 단순 반전하지 않는다.
- 노선색의 명도 대비를 테마별로 별도 검증한다.
- 표면 단계는 최대 4개로 제한한다.
- 시스템 설정을 기본으로 하되 사용자 선택을 계정과 로컬에 동기화한다.
