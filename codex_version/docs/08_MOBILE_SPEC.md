# 모바일 제품 명세

## 모바일의 역할

모바일 앱은 웹을 축소한 편집기가 아니라 여행 전후보다 여행 중에 강한 도구다. 가까운 역, 오늘 일정, 다음 이동, 시간표, 알림, 빠른 기록을 우선한다.

## 플랫폼 범위

- Phase 1에 Expo 기반 iOS/Android 동시 제공
- 태블릿은 반응형 지원하되 별도 최적화는 후순위
- 위치·푸시·딥링크·공유 시트를 네이티브 기능으로 사용
- 관리자 기능과 복잡한 데이터 편집은 웹으로 연결

## 화면 명세

| 화면 | 사용자 목표 | 1차 행동 | 정보 계층 | 오프라인/오류 | 웹과 다른 점 |
|---|---|---|---|---|---|
| 홈 | 지금 필요한 여행 정보 확인 | 오늘 계획 열기 | 오늘 계획→가까운 역→저장 장소→알림 | 마지막 동기화 표시 | 일반 홍보 홈이 아님 |
| 탐색 지도 | 주변 역·장소 찾기 | 마커/검색 | 지도→하단 시트→필터 | 캐시 결과와 온라인 여부 | 전체 화면 지도, 한 손 조작 |
| 역 상세 | 다음 열차와 주변 확인 | 시간표/장소 | 역·방향→다음 열차→장소 | 시간표 기준일 표시 | 다음 3개 열차 중심 |
| 경로 검색 | 바로 이동할 경로 찾기 | 대안 선택 | 입력→대안→타임라인 | 추정 구간 표시 | 복잡한 비교표 제거 |
| 계획 목록 | 오늘/예정 계획 찾기 | 당일 모드 시작 | 오늘→예정→초안→지난 계획 | 계획 요약 캐시 | 날짜와 실행 상태 우선 |
| 당일 모드 | 현재·다음 항목 실행 | 항목 완료 | 현재 항목→다음 이동→이후 일정 | 완료 큐 동기화 | 모바일 고유 화면 |
| 계획 간편 편집 | 시간·순서 수정 | 저장 | 날짜→항목 목록→충돌 | 낙관 업데이트/충돌 | 대규모 지도 편집은 웹 링크 |
| 후기 피드/상세 | 이동 중 경험 참고 | 저장/도움됨 | 이미지·제목→경로→본문 | 텍스트·썸네일 캐시 | 단일 열, 미디어 절약 모드 |
| 후기 빠른 작성 | 여행 직후 기록 | 초안 저장 | 계획 선택→사진→메모→평점 | 로컬 초안·업로드 큐 | 긴 편집은 웹에서 계속 |
| 모집 | 신청 상태 확인 | 신청/취소 | 날짜·남은 자리→계획→본문 | 쓰기는 온라인 필요 | 상태 알림과 연결 |
| 알림 | 상태 변화 처리 | 대상 열기 | 미읽음→종류→시간 | 마지막 목록 캐시 | 푸시 딥링크 목적지 |
| 마이/설정 | 계정·저장·권한 관리 | 항목 열기 | 프로필→저장→알림/위치→보안 | 민감 작업 온라인 | OS 권한 상태 표시 |

## 권한 요청

| 권한 | 요청 시점 | 거부 시 |
|---|---|---|
| 위치 | `가까운 역 찾기`를 사용자가 누를 때 | 역 검색·지도 수동 이동 |
| 알림 | 첫 모집 신청/여행 알림 설정 시 | 인앱 알림 유지 |
| 사진 | 후기에서 사진 추가 시 | OS 선택기 범위만 사용 |
| 카메라 | 직접 촬영 선택 시 | 사진 라이브러리 사용 |

앱 첫 실행에서 권한을 한꺼번에 요구하지 않는다.

## 오프라인 정책

읽기 가능:

- 마지막으로 동기화한 오늘/예정 계획
- 계획에 포함된 역·장소 요약과 썸네일
- 최근 조회 역의 시간표 스냅샷과 기준 시각
- 작성 중 후기 초안

온라인 필수:

- 로그인·재인증
- 모집 신청·수락·정원 변경
- 공유 링크 발급·회수
- 최신 시간표/실시간 정보
- 미디어 최종 업로드

충돌 정책:

- 계획 단순 완료 체크는 클라이언트 작업 ID로 멱등 적용한다.
- 순서·시간 편집 충돌은 서버 버전과 로컬 버전을 보여주고 선택하게 한다.
- 후기 초안은 로컬이 우선이며 게시 시 서버 검증을 받는다.

## 딥링크와 알림

- 알림 페이로드는 화면 경로가 아니라 `resourceType`, `resourceId`, `action`을 담는다.
- 앱이 없으면 같은 HTTPS 공개 URL로 열고, 보호 리소스는 설치 후 로그인 뒤 복원한다.
- 모집 신청 상태, 계획 출발 리마인더, 운영 공지를 기본 유형으로 한다.
- 마케팅 알림은 별도 동의이며 기본 비활성이다.

## 모바일 접근성·성능

- Dynamic Type/글꼴 확대 200%에서 핵심 작업이 가능해야 한다.
- TalkBack/VoiceOver 순서를 시각 순서와 일치시킨다.
- 저사양 기기에서 지도 마커 클러스터링과 이미지 크기 변형을 사용한다.
- 셀룰러에서 원본 이미지를 자동 재생·다운로드하지 않는다.
- 크래시 없는 세션 99.5% 이상을 초기 목표로 둔다.

## 모바일에서 하지 않는 것

- 장소·공지·신고 관리자 전체 화면
- 복잡한 다일정 대형 지도 편집
- 테이블형 원본 시간표 다운로드
- 영상 편집·트랜스코딩 설정
