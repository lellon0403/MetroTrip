# 프론트엔드 UI 크기 토큰 규칙

## 기본 원칙

- 고정 디자인 값은 `frontend/src/index.css`의 Tailwind v4 `@theme` 토큰으로 관리한다.
- 색상, spacing, radius, 기본 컨트롤 크기처럼 여러 화면에서 반복되는 값은 컴포넌트에 직접 작성하지 않는다.
- viewport에 따라 변하는 값은 같은 파일의 `:root` 반응형 CSS 토큰으로 관리한다.
- `clamp()`, `min()`, `dvh`, 미디어쿼리 값은 컴포넌트 안에 반복해서 작성하지 않고 역할별 토큰으로 정의한다.

## 토큰 사용 방법

컴포넌트에서는 공용 토큰을 참조한다.

```tsx
<div className="p-[var(--layout-gutter)] w-[var(--map-panel-width)]" />
```

화면 배율이나 밀도를 조정할 때는 컴포넌트의 임의값보다 `index.css`의 토큰을 먼저 수정한다.

## 토큰 그룹

- `--layout-*`: 페이지 여백과 콘텐츠 간격
- `--map-*`: 지도 장소 패널과 지도 영역
- `--timetable-*`: 시간표 패널
- `--auth-*`: 로그인·회원가입·비밀번호 찾기 화면
- `--content-*`: 일반 페이지 제목과 설명
- `--board-*`: 후기·모집처럼 목록, 상세, 작성 화면이 한 세트인 게시판 레이아웃

하나의 크기 토큰을 모든 UI에 강제로 공유하지 않는다. 의미와 사용 맥락이 다른 영역은 별도 토큰 그룹으로 유지한다.

새 토큰을 추가할 때는 기존 토큰 재사용 가능성을 먼저 확인하고, 여러 화면에서 반복되거나 공통 조정이 필요한 값만 추가한다.

## 게시판 콘텐츠 폭

- `--board-content-width`는 후기 게시판의 목록·상세·작성 화면이 공통으로 사용하는 최대 폭이다.
- 기본 폭은 `56rem`, 1920px 이상에서는 `64rem`이다. 세 화면은 `PreviewFrame`의 `contentWidth="board"` 또는 `max-w-[var(--board-content-width)]`만 사용한다.
- 이후 모집 게시판을 만들 때도 같은 폭이 적절하면 이 토큰과 `contentWidth="board"`를 재사용한다. 폭을 바꿔야 할 때는 각 화면의 className이 아니라 `frontend/src/index.css`의 토큰만 수정한다.

## 사이드바 프로필 메뉴

- 마이페이지는 주요 화면 네비게이션 목록과 분리해 사이드바 하단 프로필 메뉴로 배치한다.
- 프로필 사진 설정 기능이 없을 때는 기본 프로필 아이콘을 사용하고, 로그인 상태에 따라 배경색을 다르게 표시한다.
- 프로필 메뉴는 기존 마이페이지 라우팅과 로그인 필요 모달 동작을 그대로 사용한다.
